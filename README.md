# Filmshop API

A school project created as part of the API and database development course at Medieinstitutet.

The project is a simple REST API for a film shop, with products divided into categories.

## Built with

- Node.js
- Express
- MySQL

## Features

- Get all products
- Add products
- Get all categories
- Add categories
- Update categories
- Delete categories

## Database

The database contains two related tables:

- `products`
- `categories`

The repository also includes the SQL export and an ER diagram of the database structure.
